# Retired modelling skills

Versions 1 to 3 of the Blender modelling skill, retired on 2026-10-24 (Lachlan's pick when GloomFell came in line with the megaproject's rules). They're kept here for their reasoning, not to be run: as skills they no longer load, because they're outside `.claude/skills/`.

- `blender-model-mode/`: v1, the five-tier fleet.
- `blender-model-modev2/`: v2, supervisor plus orchestrator. Its `references/evidence.md` (the measured receipts v3 and v4 cite) now lives in the v4 skill as `references/evidence.md`.
- `blender-model-modev3/`: v3, one maker, the orbit stimulus, the user as the only promoter.

v1 and v2 ran more subagents at once, and deeper, than the subagent cap allows (8 per session, 1 below each, 2 levels). `/blender-model-modev4` (`.claude/skills/blender-model-modev4/`), one asset per session, is the one to use.
